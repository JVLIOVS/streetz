# STREETZ

Prototype de jeu d'action en monde ouvert pour mobile (web, paysage) — Three.js + Rapier.

- Jouer : lien GitHub Pages du dépôt (à ouvrir sur téléphone, en paysage ; « Ajouter à l'écran d'accueil » pour le plein écran).
- Dev : `npm install`, `npm run dev`, `npm test`, `npm run build && npm run e2e`.
- Docs : `docs/PLAN.md`, `docs/DECISIONS.md`, `docs/MULTIPLAYER.md`, `docs/CREDITS.md`, `CLAUDE.md`.
